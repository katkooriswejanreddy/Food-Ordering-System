🍔 Food Ordering System

📌 Overview

A full-stack Food Ordering System where users can browse food items, add to cart, and place orders. Includes an admin panel for managing orders and menu.

⸻

🚀 Features
	•	🧑 User authentication (Login/Register)
	•	🍕 Browse food menu
	•	🛒 Add to cart & checkout
	•	📦 Order management
	•	🛠️ Admin dashboard

⸻

🛠️ Tech Stack

Frontend: React, Vite, CSS
Backend: Node.js, Express
Database: (MongoDB)

⸻

📂 Project Structure
	•	client-side/ → Frontend (React)
	•	backend/ → API server
	•	admin-panel/ → Admin dashboard

⸻

▶️ How to Run Locally

1. Clone repo

git clone https://github.com/katkooriswejanreddy/Food-Ordering-System.git

2. Install dependencies

cd client-side && npm install
cd ../backend && npm install

3. Run project

cd client-side && npm run dev
cd ../backend && npm start
